# 화면·라우팅·사용자 흐름

## 현재 라우트와 접근

BrowserRouter를 사용한다(2026-11-03 전환). 표의 `/p/...`가 실제 브라우저 주소다. Nginx는 `/api` 밖의 모든 경로에 `index.html`을 돌려주고(`deploy/nginx/scoreroom.conf`), 예전 `/#/...` 주소는 앱 시작 시 새 주소로 바꾼다.

| 경로 | 화면 | 접근 |
|---|---|---|
| /login | 로그인 | 미로그인; 로그인 완료자는 시작 화면으로 |
| /signup | 가입 | 가입 정책 확정 후 운영 노출 |
| /find-id, /find-pw | 계정 복구 | 본인 확인 절차가 구현된 경우만 운영 노출 |
| / | 평가룸 목록·생성·코드 입장 | 일반 회원/전체 열람자 |
| /sys | 조직도와 사용자 관리 | 시스템 관리자 |
| /sys/viewers | 전체 열람 권한 관리 | 시스템 관리자 |
| /p/:pid | 발표 목록·구성원별 내 평가 | 참여자 또는 전체 열람자; 평가는 참여자만 |
| /p/:pid/pres/new | 발표 등록 | OPEN 룸 참여자 |
| /p/:pid/pres/:prid | 발표 편집 | OPEN 룸의 대표/작성자/룸 운영자 |
| /p/:pid/results | 결과 | 룸 운영자 또는 전체 열람자 |
| /p/:pid/admin | 룸 운영 | 룸 운영자 |

관리자 화면 탭은 `?tab=run|invite|members|settings`로 표현한다. 현재 `tab=result`는 results로 리다이렉트된다. 개인정보 수정/회사 조직도/결과 PNG 내보내기는 별도 라우트가 아닌 팝업이다. 시스템 관리자는 룸 참여 흐름으로 이동하지 않는다.

## 화면 책임

- 평가룸 목록: 내 룸과 권한에 따른 전체 룸 표시, 생성과 코드 입장, 검색·정렬·페이지 관리.
- 발표 목록: 평가 대상별 TODO/DONE/BLOCKED/MISSED 상태와 내 점수/피드백, 첨부 접근.
- 발표 폼: PERSONAL/TEAM, 대표·발표자·팀원 선택, 대표 발표 겸임, 파일 추가/삭제. 점수를 받은 발표의 구성원 추가/제외는 잠근다.
- 운영 화면: 마감, 코드 발급/중지, 개별 사용자 초대, 순서 이동, 멤버 권한, 설정 영향 확인.
- 결과: 발표 구성원별 제출 수/평균/범위 평균/순위. 운영자는 평가자별 점수와 피드백 상세를 볼 수 있다. 전체 열람자는 집계만 본다.
- 시스템 관리: 팀 계층/소속/직위/순서/전체 열람 권한 관리.

## 주요 흐름

로그인: CSRF 조회 → 자격 정보 전송 → 세션 확인 `/me` → CSRF 재조회 → 역할별 시작 화면. 초기 인증 확인 동안 로그인 화면과 보호 화면이 번갈아 표시되지 않도록 로딩 상태를 둔다.

평가 제출: 점수 입력 → 정수/범위와 피드백 길이 확인 → 해당 대상 제출 버튼 잠금 → 서버 저장 → 내 평가와 진행 상태 갱신. 성공 확인 전 완료 배지를 표시하지 않는다. 대상별 요청을 구분해 다른 사람의 입력을 막지 않는다.

발표 저장: 본문 저장과 파일 변경은 여러 요청이다. 본문 저장 성공 후 파일 2개 중 1개가 실패하면 전체 실패처럼 표시하지 않고 저장된 내용/실패 파일을 구분한다. 성공한 파일을 다시 올리지 않고 실패 건만 재시도한다. 폼 이탈 시 미저장 변경 확인을 제공한다.

위험 작업: 설정/참여자 제거 영향 조회 → 삭제할 평가 수 등 표시 → 사용자가 확인 → 같은 version으로 변경 요청. 409이면 영향 조회를 다시 수행하고 재확인을 받는다. 이전 확인을 근거로 새 영향 범위를 자동 승인하지 않는다.

초대 수락: 요청 → 내 초대/룸 목록 갱신 → 해당 룸 이동. 이미 처리된 초대는 현재 상태를 새로 조회하고 알린다. 코드의 화면 카운트다운은 안내이며 만료 판정은 서버가 담당한다.

## 로딩·실패·권한 상태

첫 조회 로딩, 정상 빈 목록, 네트워크 실패, 권한 없음, 리소스 삭제를 구분한다. 조회 중이라고 없는 룸으로 판단해 홈으로 보내지 않는다. 401은 인증 만료, 403은 접근 불가, 404는 삭제/잘못된 주소로 표시한다. 배경 갱신 실패 시 기존 데이터는 남기고 마지막 갱신 시각과 재시도를 표시한다.

결과 PNG 내보내기는 현재처럼 옵션 → 테마 → 미리보기 → 다운로드 흐름을 유지한다. 공개 링크 생성 기능으로 확장하지 않는다. 기존 운영자용 노출 정책을 유지하고 생성 시점의 서버 집계 스냅샷을 사용한다. 동점 순위 방식은 별도 확정해야 하며 화면과 이미지에서 같은 함수를 사용한다.
