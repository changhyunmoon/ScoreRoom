# ScoreRoom

사내 발표 평가 서비스의 React 화면 시안입니다. 현재는 프론트엔드 목업이며, 데이터는 브라우저 `localStorage`에 저장됩니다. 백엔드와 AWS 배포 구성은 아직 포함되지 않았습니다.

## 실행

```bash
cd frontend
npm ci
npm run dev
```

기본 개발 주소는 `http://localhost:5173`입니다. 로그인 화면의 빠른 로그인으로 시안 계정을 선택할 수 있습니다.

## 현재 화면

- 평가룸 생성과 입장 코드 참여
- 발표 등록, 발표 순서 및 진행 관리
- 개인 평가와 룸 운영자 전용 실시간 결과 시안
- 회사 팀 구조도와 사용자 정보 관리

같은 브라우저의 탭 사이에서는 변경 사항이 반영되지만, 다른 기기와 데이터를 공유하는 서버 기능은 아직 없습니다. 자세한 화면 구조는 [프론트엔드 README](frontend/README.md)를 참고하세요.
