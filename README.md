# ScoreRoom 목업

사내 발표 평가 서비스의 React 화면 목업입니다. 데이터 처리도 브라우저 안에서 이루어지며 백엔드나 데이터베이스 없이 실행됩니다.

## 실행

```bash
cd frontend
npm ci
npm run dev
```

화면은 `http://localhost:5173`에서 열 수 있습니다. 로그인 화면의 **목업 모드 빠른 로그인**에서 계정을 선택하면 됩니다. 모든 목업 계정의 비밀번호는 `1234`입니다.

`npm run build`와 `npm run preview`로 실행한 결과도 같은 목업 데이터를 사용합니다.

## 데이터

팀, 사용자, 평가룸, 발표, 평가와 초대 데이터는 브라우저 `localStorage`에, 업로드한 발표 자료는 `IndexedDB`에 저장됩니다. 로그인 상태는 탭의 `sessionStorage`에 저장됩니다. 로그인 화면의 **목업 데이터 초기화**를 누르면 해당 브라우저의 목업 데이터와 업로드 자료가 초기 상태로 돌아갑니다.

화면 및 데이터 구조는 [프론트엔드 안내](frontend/README.md)를 참고하세요.
